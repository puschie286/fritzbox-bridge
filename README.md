supported devices:
* CometDECT, Fritz!DECT 300/301
* Fritz!DECT 200/210, FRITZ!Powerline 546E
* HANFUN Alarm
* FRITZ!Box
* RolloTron DECT
* DECT 500
* DECT 400/440

require a user account with "FRITZ!Box-Settings" permissions (or at least "Smart Home" ).
More information under [AVM Knowledge base](https://en.avm.de/service/knowledge-base/dok/FRITZ-Box-7369-int/1522_Accessing-FRITZ-Box-from-the-home-network-with-user-accounts/)

supported sensors & values:
https://github.com/puschie286/fritzbox-bridge/wiki/Supported-devices-&-sensors

Used icons from: https://www.flaticon.com/authors/freepik

known limits:
* CometDECT
  * measurements have a delay ( max. 15min )
  * sending commands can take up to 15min to take effect
  * temperature sensor has higher resolution internal
* DECT 400/440
  * buttons are visible on device despite not manual trigger able
  * wrong trigger cards may be displayed after adding ( restart of app should fix that )
  * trigger delay depends on polling interval ( can be changed in app setting )

## Development setup

This is a TypeScript app using Homey Apps SDK v3, Homey Compose and the local
Homey platform. Install **Node.js 24 or newer** and npm before working on the app.
The repository includes the Homey CLI as a development dependency, so a global
CLI installation is optional. `.nvmrc` selects Node.js 24 when using a compatible
Node version manager.

From the repository root:

```sh
npm ci
npm run typecheck
npm run lint
npm run validate
npm run build:app
```

`npm ci` installs the versions in `package-lock.json`. After changing dependencies,
use `npm install` and commit both package files. Do not use `--legacy-peer-deps`:
Athom's configuration requires ESLint 8.57.1, and ESLint 9/10 are incompatible.

`npm run build` compiles TypeScript to `.homeybuild/` with source maps.
`npm run build:app` creates the complete Homey package, including production
dependencies and assets. `npm run validate` compiles and validates the app at
Homey's publish level without installing it on a Homey.

The lint configuration uses correctness rules from ESLint, TypeScript ESLint and
Homey, supplied by `eslint-config-athom`, while retaining the existing code style.
Dynamic Fritzbox responses, CommonJS imports and existing TypeScript suppression
comments are supported. Browser settings scripts use browser globals; timer rules
for Homey app lifecycle cleanup apply only to the app code.

To run on your Homey, authenticate and select your device with the local CLI:

```sh
npx --no-install homey login
npx --no-install homey select
npm run run
```

Docker is required for the Homey CLI's Docker development environment. Configure
the Fritzbox URL and credentials in the app settings after installation.
`npm run publish` publishes through Homey's CLI and requires developer access.

Edit `.homeycompose/app.json`, the capability and flow definitions under
`.homeycompose/`, and the drivers' `*.compose.json` files. The root `app.json` is
generated by Homey Compose. Build output belongs in `.homeybuild/`; it is ignored
by Git. `.homeyignore` excludes development examples and documentation from the
installed app while retaining the App Store description in `README.txt`.

The local development CLI's Node.js requirement is separate from Homey's runtime.
The app retains its existing Homey `>=5.0.0` compatibility and compiles to ES2019
CommonJS; app code must avoid runtime APIs unavailable on older Homey versions.

Dependency audits still report vulnerabilities in the legacy `fritzapi` /
`request` stack and dependencies supplied by the Homey CLI. Compatible audit
updates are applied in the lockfile; remaining issues require upstream fixes or
an API migration. `npm audit --omit=dev` checks dependencies shipped with the app.
Do not use `npm audit fix --force`, which proposes incompatible CLI changes.

See the official [Homey development setup](https://apps.developer.homey.app/the-basics/getting-started),
[TypeScript guide](https://apps.developer.homey.app/guides/tools/typescript), and
[Athom package requirements](https://github.com/athombv/eslint-config-athom/blob/master/package.json).
